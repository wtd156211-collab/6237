# 有向无环图的自动分层布局

我们给内部流程编排工具画流程图。现在是把节点随便往画布上一扔，线乱成一团，几十个节点的图根本看不懂。想写一个自动分层的布局库。

输入是**有向无环图**，输出是每个节点的层次、层内顺序，以及一个交叉数指标。规则写死：边的方向决定层次先后，同一层的节点之间不能有边，层数要尽量少但不能牺牲可读性；交叉数是重点，相邻两层之间连线互相穿插的次数要尽量少，但不要求全局最优，压到下面给的上界以内就行；结果必须确定，启发式遇到并列要有明确的打破规则；图里有环时不许转不出来，要报出环上的节点；孤立节点、只有一个节点、好几个互不相连的部分都要有明确行为；性能上几百个节点、上千条边的图要在几秒内算完。实现只用标准库，测试用 unittest。

仓库里只有这份说明和 samples 里的图与期望结果，代码从零写。

## 层次规则

- 输入是 `{"nodes": [...], "edges": [[u, v], ...]}`，边 `u → v` 表示 `u` 在 `v` 之前；重复边去重（交叉数也按去重后的边算）；
- **层次**用最长路径分层：入度为 0 的节点在第 0 层，其余节点 `layer(v) = 1 + max(layer(u))`（取该节点所有入边的起点），这样层数最少、且同一层内一定没有边；
- 孤立节点（既无入边也无出边）在第 0 层；
- 多个互不相连的分量各自独立分层，都从第 0 层起步，所以不同分量的节点可以落在同一层；
- 空图输出 0 层、0 节点；只有一个节点时它就是第 0 层。

## 层内排序规则

1. **初始顺序**：每层按节点 id 的 UTF-8 字节序升序（保证起点确定）；
2. **重心法**：做 4 轮扫描，向下扫时用上一层算本层节点的重心（该节点所有上层邻居位置的平均值），向上扫时用下一层；没有邻居的节点用自己当前的位置当重心；
3. **并列打破**：重心相同就按节点 id 的 UTF-8 字节序升序——这条写死，任何并列都不许靠遍历顺序决定；
4. **只保留更优的轮次**：每轮算一次总交叉数，只有**严格更小**才采纳这一轮的排序，否则回退到已记录的最优排序。

## 指标定义

**交叉数**是相邻两层之间交叉的对数之和。对相邻两层上的两条边 `(u₁,v₁)`、`(u₂,v₂)`，令 `du = pos(u₁) − pos(u₂)`、`dl = pos(v₁) − pos(v₂)`（`pos` 是层内位置，从 0 开始）；当 `du × dl < 0` 时记一次交叉（无序对只算一次）。总交叉数 = 每一对相邻层的交叉数之和。

## 环检测

发现环时不做布局，只输出一行 `error,CYCLE,<节点>-><节点>->…-><起点>`。检测顺序写死：节点按 id 字节序升序做深度优先，出边也按 id 升序，第一次遇到回边就报出这条环（自环也是环）。

## 输出格式

```text
nodes=6
edges=5
layers=3
crossings=0
pair,0,0
pair,1,0
layer,0,a,b,c
layer,1,f,e
layer,2,d
```

- 前四行分别是节点数、去重后的边数、层数、总交叉数；
- `pair,<层号>,<交叉数>`：相邻两层之间的交叉数，层号从 0 开始；
- `layer,<层号>,<节点列表>`：该层按最终顺序列出节点（逗号分隔）；
- 出错时整个输出只有一行 `error,<错误码>,<detail>`；目前只有 `CYCLE` 与 `UNKNOWN_NODE`（边引用了不存在的节点）。

## 性能要求

- 几百个节点、上千条边的图要在**几秒**内算完；交叉数统计不要写成对所有边两两比较的平方级实现；
- 同一张图跑两遍，层次分配与层内顺序必须逐字节一样。

## 样例

| 用例 | 内容 | 期望 |
| --- | --- | --- |
| case-1 | 空图 | 0 层 |
| case-2 | 单节点 | 1 层 |
| case-3 | 全是孤立节点 | 同层按 id 排序 |
| case-4 | 小 DAG，初始顺序有交叉 | 重心排序后交叉数降到 0 |
| case-5 | 三个互不相连的分量 | 各自分层，交叉数 0 |
| case-6 | 含环 | `error,CYCLE,a->b->c->a` |
| case-7 | 360 个节点、956 条边 | 交叉数在上界以内 |

每张图的 `crossing_bound` 就是**硬指标上界**（按参考实现实测值留 50% 余量再加 3），总交叉数不超过它就算过。

## 使用方式

命令行（参数为图文件，省略则从标准输入读）：

```bash
python3 dag_layout.py samples/case-4.graph.json
cat samples/case-4.graph.json | python3 dag_layout.py
```

出错（环、未知节点）时输出 `error` 行并以退出码 1 结束，正常时退出码 0。

作为库使用：

```python
import dag_layout

result = dag_layout.layout_graph({"nodes": [...], "edges": [[u, v], ...]})
# result.layers         每层一个列表，层内为最终顺序
# result.crossings      总交叉数
# result.pair_crossings 每对相邻层的交叉数
text = dag_layout.format_graph(graph)   # 直接拿到上面格式的输出文本（含 error 行）
```

`layout_graph` 有环时抛 `CycleError`（`.cycle` 为环上的节点序列），边引用未知节点时抛
`UnknownNodeError`（`.node` 为缺失的节点 id）。

测试：`python3 -m unittest`（或 `python3 -m unittest -v`）。

## 实现说明

代码在 `dag_layout.py`，只用标准库，测试在 `test_dag_layout.py`。

**分层（一次遍历）**：先按 Kahn 算法做拓扑排序——初始队列是所有入度为 0 的节点
（按 id 字节序入队），每弹出一个节点就把它所有后继的剩余入度减 1，减到 0 即入队。
弹出节点 `u` 时它的全部前驱都已出队、层次已定，于是直接递推
`layer(u) = 1 + max(layer(p))`（无前驱时取 0），拓扑遍历一遍就算完所有层次，
不需要反复扫描。之后按层次分桶，每层按 id 的 UTF-8 字节序升序得到初始顺序。
孤立节点没有前驱，自然落在第 0 层；不同分量各自从第 0 层起步，互不影响。

**重心扫描**：共 4 轮，每轮 = 一次向下扫描（从上到下处理第 1..L-1 层，用每个节点在
上一层邻居位置的平均值作重心）+ 一次向上扫描（从下到上处理第 L-2..0 层，改用下一层
邻居）。相邻层没有邻居的节点用自己当前的位置当重心。排序键是 `(重心, id 的 UTF-8
字节序)`，任何并列都按 id 字节序打破，不依赖遍历顺序。每轮结束后算一次总交叉数，
严格更小才采纳这一轮，否则回退到已记录的最优排序；初始顺序作为第一份最优记录，
所以 4 轮之后的结果不会比不排序更差。整个流程没有随机数、没有依赖哈希遍历顺序的
并列，同一张图跑两遍输出逐字节一致。

**交叉数统计**：只有端点落在相邻两层的边参与计数。对每对相邻层，把其间所有边按
`(上层端点位置, 下层端点位置)` 排序，则下层端点位置序列的**逆序对数**就是这对层的
交叉数（`du × dl < 0` 等价于逆序）；用树状数组（Fenwick）求逆序对，单层对
O(E log W)，W 是下层宽度，全图合计 O(E log W)，不是边两两比较的平方级实现。
360 节点、956 条边的 case-7 全程约 0.02 秒。
